An enterprise-grade, full-stack **MERN** digital monitoring and hydro-intelligence platform designed for Water Resource Departments to monitor groundwater levels, artificial recharge structures, borewells, and sectoral extraction patterns with **AI-driven forecasting**.

---

## 🌟 Key Features

- **Executive Hydro-Informatics Dashboard**: Real-time KPI telemetry, dynamic area hydrograph charts, pie charts for sectoral quotas, and live AI intelligence dispatch.
- **Dynamic Liquid Aquifer Reservoir Simulator**: Real-time animated SVG water wave gauge displaying basin infiltration saturation.
- **Interactive Multi-Layer GIS Satellite Map**: Seamless toggle between **Cyber Dark Matrix**, **ESRI Satellite Imagery**, and **Heatmap drawdown radial zones** with 3D pulsing markers.
- **Borewell Telemetry & Inventory**: Full CRUD registry for borewells with yield rates, pump specifications, geo-coordinates, and search/filtering.
- **Artificial Recharge & Check Dams**: Storage capacity tracking, condition monitoring, and annual subsurface percolation estimation.
- **Extraction Patterns & Surges**: 24-hour diurnal pumping profiles, sectoral allocations, and over-extraction anomaly flags.
- **AI Hydro-Intelligence Copilot & 90-Day Forecaster**: LSTM ensemble neural network predicting 30/60/90-day aquifer drawdowns with 90% confidence bands, plus a natural language AI Copilot.
- **Climate & Extraction Scenario Simulator**: Test real-time impacts of +30% monsoon rain or summer heatwaves on regional water tables.
- **Alerts & Threshold Management**: Severity-based alerts (Critical, High, Medium) with one-click resolution workflows.
- **Global Command Palette (`Ctrl + K`)**: Rapid keyboard-driven navigation across all modules and telemetry stations.
- **Dual-Theme Engine**: Instant toggle between **Cyber-Aqua Dark Mode** and **Clean Light Aqua Mode**.

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, React Router DOM v6, Lucide Icons, Recharts, Leaflet, React-Leaflet
- **Styling**: Vanilla CSS Design System with Cyber-Aqua tokens, Glassmorphism, CSS Grid & Micro-animations
- **Backend**: Node.js, Express.js, JWT, Mongoose, Helmet, CORS, Morgan
- **AI & ML**: Brain.js LSTM Neural Network, Google Generative AI (Gemini SDK)
- **Database**: MongoDB Atlas / Local MongoDB

## 🚀 Quick Start Guide

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- [Git](https://git-scm.com/)

### Installation & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/aquavision.git
   cd aquavision
   ```

2. **Install all dependencies**:
   ```bash
   npm run install-all
   ```

3. **Start the Frontend Client**:
   ```bash
   npm run client
   ```
   *Frontend opens at `http://localhost:5173/`*

4. **Start the Backend Server (Optional / Full-Stack Mode)**:
   ```bash
   npm run server
   ```
   *API runs at `http://localhost:5000/`*

5. **Run Both Concurrently**:
   ```bash
   npm run dev
   ```
